# Mini seznam nalog

Preprosta spletna aplikacija za dodajanje, označevanje in brisanje nalog.
Testni projekt za vaje iz Gita in GitHuba (FERI).

## Zagon
Odpri `index.html` v brskalniku. Namestitev ni potrebna.

## Uporaba
- Vpiši nalogo in klikni **Dodaj**
- Klik na nalogo jo označi kot opravljeno
- Klik na ✕ nalogo izbriše

## Struktura
- `index.html` – stran
- `style.css` – izgled
- `app.js` – logika
